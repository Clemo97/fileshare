Support

How to send a file, and what to try when it does not work.

Send your first file

  1. Open Acornet on both devices.
  2. On the first device, tap Connect Device, then Generate Connection Code.
  3. On the second device, tap Connect Device and type in the code.
  4. On either device, tap Send Files and choose what to send.
  5. On the other device, accept the transfer.

Once two devices are paired they stay paired, so next time you can go straight to Send Files.

When something goes wrong

The code does not work

Codes last five minutes and work once. Generate a new one on the first device and try again. If a device enters a wrong code five times within ten minutes, it has to wait before it can try again.

The transfer will not start, or stops

Keep Acornet open on both devices until the transfer finishes. When an app goes to the background, the system can pause it and the transfer stops.

Some networks block direct connections between devices, for example guest Wi-Fi, some workplaces and some mobile data connections. If a transfer fails there, try both devices on a different network.

A received file has disappeared

Received files wait in the app's temporary storage, and the system may clear that storage when space runs low. After a file arrives, use the share sheet to save it, for example to Files.

I want to delete my data

On the home screen, tap Delete account and confirm. This removes your account and the pairings, codes, requests and connection messages linked to it. Files you already saved on your devices stay there. The privacy policy has the details.
