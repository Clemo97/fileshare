# Store submission material for Acornet

Drafts for the first App Store release, 2026-11-03. Nothing here is submitted; the owner enters it in App Store Connect and presses Submit for Review. The release steps are in `../RELEASE_PLAN.md`.

| File | What it is |
|---|---|
| `listing.md` | Name, subtitle, promotional text, description, keywords, URLs, copyright, categories |
| `review-notes.md` | App Review contact fields and the notes to paste |
| `privacy-and-age-rating.md` | Age-rating and App Privacy answers with the reasoning, EU trader status, the open export-compliance question |
| `screenshots/iphone/` | Six iPhone screenshots, 1206 x 2622 px, no alpha. Upload order: 01 to 06 |
| `screenshots/ipad/` | iPad 13-inch screenshots, 2064 x 2752 px, no alpha. **Not captured yet** (`../HANDOFF.md` G27) |

The screenshots show the real app screens with sample data (the app's built-in demo scenarios): Apple wants screenshots of the app in use, and a live transfer between two real devices would show the same screens.

The screen recording for App Review is best made on real devices (see `review-notes.md`); save it here as `review-video.mov`. It is not committed (see `.gitignore`).
